λ 演算

项的语法与括号约定

纯 λ 演算的项由三种形式递归构成：

M,N::=x∣λx.M∣M NM,N ::= x \mid \lambda x.M \mid M\,N M,N::=x∣λx.M∣MN

  • xxx 是变量；λx.M\lambda x.Mλx.M 是以 xxx 为参数、MMM 为函数体的匿名函数（抽象）；M NM\,NMN 是把函数 MMM 应用于实参 NNN（应用）。
  • 抽象的函数体尽可能向右延伸：λx.M N=λx.(M N)\lambda x.M\,N = \lambda x.(M\,N)λx.MN=λx.(MN)。
  • 应用向左结合：M N P=(M N) PM\,N\,P = (M\,N)\,PMNP=(MN)P。要表达不同结构须加括号。

纯 λ 演算没有内建数字或 +；讲义中的数值运算例子是在扩展语言中说明语法，后面会用 λ 项编码数据。

自由变量与绑定

在 λx.M\lambda x.Mλx.M 中，λx\lambda xλx 绑定其函数体 MMM 内相应的 xxx 出现；不受该绑定覆盖的变量出现是自由的。区分的是出现位置，同一个变量名可以在一项中既有自由出现，也有绑定出现。

自由变量集合按项的结构定义：

FV(x)={x},FV(λx.M)=FV(M)∖{x},FV(M N)=FV(M)∪FV(N).\mathrm{FV}(x)=\{x\},\qquad \mathrm{FV}(\lambda x.M)=\mathrm{FV}(M)\setminus\{x\},\qquad \mathrm{FV}(M\,N)=\mathrm{FV}(M)\cup\mathrm{FV}(N).FV(x)={x},FV(λx.M)=FV(M)∖{x},FV(MN)=FV(M)∪FV(N).

例如，FV((λx.x) x)={x}\mathrm{FV}((\lambda x.x)\,x)=\{x\}FV((λx.x)x)={x}：函数体内的 xxx 被绑定，实参处的 xxx 是自由的。自由变量集合为空的项称为封闭项。

只重命名被绑定的变量及其对应出现，且不改变变量的绑定关系，得到的项称为 α 等价。例如 λx.x y\lambda x.x\,yλx.xy 与 λz.z y\lambda z.z\,yλz.zy α 等价；自由变量 yyy 不能随意改名。重命名时还须避免意外捕获原本自由的变量。

例如，将 λx.x y\lambda x.x\,yλx.xy 中绑定的 xxx 改名为 yyy，会得到 λy.y y\lambda y.y\,yλy.yy：原本自由的 yyy 被新绑定的 λy\lambda yλy 捕获，因此两项不 α 等价。改用新变量 zzz，得到 λz.z y\lambda z.z\,yλz.zy，则保留了原来的绑定关系。

替换

M[N/x]M[N/x]M[N/x] 表示把 MMM 中自由出现的 xxx 替换为项 NNN；NNN 可以是变量、抽象或应用。变量和应用上的规则为 x[N/x]=Nx[N/x]=Nx[N/x]=N、y[N/x]=yy[N/x]=yy[N/x]=y（y≠xy\ne xy=x）、(M P)[N/x]=M[N/x] P[N/x](M\,P)[N/x]=M[N/x]\,P[N/x](MP)[N/x]=M[N/x]P[N/x]。例如 (x x)[λz.z /x]=(λz.z)(λz.z)(x\,x)[\lambda z.z\,/x]=(\lambda z.z)(\lambda z.z)(xx)[λz.z/x]=(λz.z)(λz.z)。

  • 遇到 λx.M\lambda x.Mλx.M 时停止：(λx.M)[N/x]=λx.M(\lambda x.M)[N/x]=\lambda x.M(λx.M)[N/x]=λx.M；其中的 xxx 已被绑定。
  • 遇到 λy.M\lambda y.Mλy.M（y≠xy\ne xy=x）时，若 y∉FV(N)y\notin\mathrm{FV}(N)y∈/FV(N)，可进入函数体：(λy.M)[N/x]=λy.(M[N/x])(\lambda y.M)[N/x]=\lambda y.(M[N/x])(λy.M)[N/x]=λy.(M[N/x])。
  • 若 y∈FV(N)y\in\mathrm{FV}(N)y∈FV(N)，先将绑定的 yyy α 重命名为新变量，再替换，避免捕获 NNN 中自由的 yyy。

例如，(λy.x y)[y/x]=λz.y z(\lambda y.x\,y)[y/x]=\lambda z.y\,z(λy.xy)[y/x]=λz.yz，其中 zzz 是新变量。直接得到 λy.y y\lambda y.y\,yλy.yy 会错误地绑定替入项中的自由 yyy。

β 归约

把抽象应用于实参时，进行避免捕获的替换：

(λx.M) N  →β  M[N/x].(\lambda x.M)\,N\;\to_\beta\;M[N/x]. (λx.M)N→β​M[N/x].

形如 (λx.M) N(\lambda x.M)\,N(λx.M)N 的子项称为 β-redex（可归约式）。一次 β 归约可发生在整个项或其子项中。例如，((λx.x) (λz.z)) w→β(λz.z) w→βw((\lambda x.x)\,(\lambda z.z))\,w\to_\beta(\lambda z.z)\,w\to_\beta w((λx.x)(λz.z))w→β​(λz.z)w→β​w。括号决定每一步归约的是哪个应用。

β 范式

β 范式是任何位置都不含 β-redex 的项；此时无法继续做 β 归约。检查范围包括抽象的函数体，例如 λx.(λy.y) x\lambda x.(\lambda y.y)\,xλx.(λy.y)x 仍含可归约式，而 λx.x\lambda x.xλx.x 是 β 范式。项 x (λy.y)x\,(\lambda y.y)x(λy.y) 也是 β 范式：右侧虽是函数，但左侧 xxx 不是抽象。

归约未必终止。令 Ω=(λx.x x)(λx.x x)\Omega=(\lambda x.x\,x)(\lambda x.x\,x)Ω=(λx.xx)(λx.xx)，则 Ω→βΩ→β⋯\Omega\to_\beta\Omega\to_\beta\cdotsΩ→β​Ω→β​⋯，没有 β 范式。

归约顺序

当一项中有多个 β-redex 时，需要选归约顺序。正规序每步选最左、最外层的可归约式；应用序每步选最左、最内层的可归约式。

例如 (λu.λv.v) Ω(\lambda u.\lambda v.v)\,\Omega(λu.λv.v)Ω：正规序先归约外层，直接得到 λv.v\lambda v.vλv.v；应用序先归约实参中的 Ω\OmegaΩ，而 Ω→βΩ\Omega\to_\beta\OmegaΩ→β​Ω，因而一直循环。若一个项存在 β 范式，正规序归约能找到它；应用序不一定能找到。

合流性

M→β∗NM\to_\beta^*NM→β∗​N 表示经过零步或多步 β 归约从 MMM 到 NNN。合流性：若 M→β∗M1M\to_\beta^*M_1M→β∗​M1​ 且 M→β∗M2M\to_\beta^*M_2M→β∗​M2​，则存在 PPP，使 M1→β∗PM_1\to_\beta^*PM1​→β∗​P 且 M2→β∗PM_2\to_\beta^*PM2​→β∗​P（变量名差别按 α 等价看待）。因此，一个项若有 β 范式，它在 α 等价意义下唯一。

例如 (λx.x)((λy.y)z)(\lambda x.x)((\lambda y.y)z)(λx.x)((λy.y)z) 可以先归约外层或内层；两条路径最终都到 zzz。合流性不保证每条归约路径都终止，例如 (λu.λv.v)Ω(\lambda u.\lambda v.v)\Omega(λu.λv.v)Ω 仍可沿归约 Ω\OmegaΩ 的路径无限循环。

归约与求值

完全 β 归约以 β 范式为目标，可以进入抽象的函数体继续归约。讲义中的求值针对封闭项，以抽象 λx.M\lambda x.Mλx.M 作为典范形式；一旦整个项成为抽象就停止，不继续归约其函数体。

例如，封闭项 λx.(λy.y)x\lambda x.(\lambda y.y)xλx.(λy.y)x 已是典范形式，求值在此停止；但它仍含 β-redex，完全归约可继续得到 λx.x\lambda x.xλx.x。因此，典范形式不一定是 β 范式。

传名与传值求值

两种求值方式都在得到抽象时停止，不进入函数体；区别在应用时是否先求实参。

  • 传名（call-by-name）：(λx.M)N(\lambda x.M)N(λx.M)N 可直接替换为 M[N/x]M[N/x]M[N/x]，实参 NNN 不必先求值。
  • 传值（call-by-value）：先将实参求值为抽象 VVV，再把 (λx.M)V(\lambda x.M)V(λx.M)V 替换为 M[V/x]M[V/x]M[V/x]。

例如，(λx.λy.y)Ω(\lambda x.\lambda y.y)\Omega(λx.λy.y)Ω 在传名下直接得到 λy.y\lambda y.yλy.y；在传值下为求出实参 Ω\OmegaΩ 而发散。传名/传值与对整个项持续归约到 β 范式的正规序/应用序相似，但停止条件不同。

Church 布尔值

用“从两个候选项中选择一个”的函数编码布尔值：

True≡λx.λy.x,False≡λx.λy.y.\mathrm{True}\equiv\lambda x.\lambda y.x,\qquad \mathrm{False}\equiv\lambda x.\lambda y.y.True≡λx.λy.x,False≡λx.λy.y.

因此 True M N→β∗M\mathrm{True}\,M\,N\to_\beta^*MTrueMN→β∗​M，False M N→β∗N\mathrm{False}\,M\,N\to_\beta^*NFalseMN→β∗​N；条件表达式 if b then M else N\text{if }b\text{ then }M\text{ else }Nif b then M else N 可写成 b M Nb\,M\,NbMN。取反可定义为 not≡λb.b False True\mathrm{not}\equiv\lambda b.b\,\mathrm{False}\,\mathrm{True}not≡λb.bFalseTrue。

同理，or≡λb.λc.b True c\mathrm{or}\equiv\lambda b.\lambda c.b\,\mathrm{True}\,cor≡λb.λc.bTruec：bbb 为真时选 True\mathrm{True}True，否则选 ccc。

and≡λb.λc.b c False\mathrm{and}\equiv\lambda b.\lambda c.b\,c\,\mathrm{False}and≡λb.λc.bcFalse：bbb 为真时选 ccc，否则选 False\mathrm{False}False。

Church 数

自然数 nnn 用“把函数 fff 对初值 xxx 应用 nnn 次”的函数表示：n‾≡λf.λx.fn(x)\overline n\equiv\lambda f.\lambda x.f^n(x)n≡λf.λx.fn(x)，其中 f0(x)=xf^0(x)=xf0(x)=x。

0‾≡λf.λx.x,1‾≡λf.λx.f x,2‾≡λf.λx.f (f x).\overline 0\equiv\lambda f.\lambda x.x,\qquad \overline 1\equiv\lambda f.\lambda x.f\,x,\qquad \overline 2\equiv\lambda f.\lambda x.f\,(f\,x).0≡λf.λx.x,1≡λf.λx.fx,2≡λf.λx.f(fx).

例如 2‾ g a→β∗g (g a)\overline 2\,g\,a\to_\beta^*g\,(g\,a)2ga→β∗​g(ga)。这些数是纯 λ 项；上横线用于区分编码项与通常的数字。

后继

给 Church 数表示的 nnn 再增加一次 fff 的应用：

succ≡λn.λf.λx.f (n f x).\mathrm{succ}\equiv\lambda n.\lambda f.\lambda x.f\,(n\,f\,x). succ≡λn.λf.λx.f(nfx).

例如 succ  2‾  g  a→β∗g (g (g a))\mathrm{succ}\;\overline 2\;g\;a\to_\beta^*g\,(g\,(g\,a))succ2ga→β∗​g(g(ga))，即 3‾  g  a\overline 3\;g\;a3ga。这里 n f xn\,f\,xnfx 已经应用 nnn 次，外层的 fff 再应用一次。

零判断

iszero≡λn.λx.λy.n (λz.y) x.\mathrm{iszero}\equiv\lambda n.\lambda x.\lambda y.n\,(\lambda z.y)\,x. iszero≡λn.λx.λy.n(λz.y)x.

Church 数 nnn 把函数 λz.y\lambda z.yλz.y 对初值 xxx 应用 nnn 次。若 n=0n=0n=0，结果仍是 xxx，即 True≡λx.λy.x\mathrm{True}\equiv\lambda x.\lambda y.xTrue≡λx.λy.x；若 n>0n>0n>0，第一次应用便得到 yyy，之后始终是 yyy，即 False≡λx.λy.y\mathrm{False}\equiv\lambda x.\lambda y.yFalse≡λx.λy.y。

令 F=λz.yF=\lambda z.yF=λz.y。则 1‾ F x→F x→y\overline 1\,F\,x\to F\,x\to y1Fx→Fx→y；2‾ F x→F (F x)→F y→y\overline 2\,F\,x\to F\,(F\,x)\to F\,y\to y2Fx→F(Fx)→Fy→y。因此一次及以上的应用都会选第二个分支。

加法与乘法

将 mmm 次迭代与 nnn 次迭代接起来，得到加法：

add≡λn.λm.λf.λx.n f (m f x).\mathrm{add}\equiv\lambda n.\lambda m.\lambda f.\lambda x.n\,f\,(m\,f\,x). add≡λn.λm.λf.λx.nf(mfx).

将“应用 fff 共 mmm 次”视为一次新操作，再将这项操作重复 nnn 次，得到乘法：

mult≡λn.λm.λf.λx.n (m f) x.\mathrm{mult}\equiv\lambda n.\lambda m.\lambda f.\lambda x.n\,(m\,f)\,x. mult≡λn.λm.λf.λx.n(mf)x.

序对与元组

序对把两个项交给一个接收两项的函数处理。选取新变量 sss，定义 (M,N)≡λs.s M N(M,N)\equiv\lambda s.s\,M\,N(M,N)≡λs.sMN。令 fst≡λp.p True\mathrm{fst}\equiv\lambda p.p\,\mathrm{True}fst≡λp.pTrue、snd≡λp.p False\mathrm{snd}\equiv\lambda p.p\,\mathrm{False}snd≡λp.pFalse，便有 fst(M,N)→β∗M\mathrm{fst}(M,N)\to_\beta^*Mfst(M,N)→β∗​M、snd(M,N)→β∗N\mathrm{snd}(M,N)\to_\beta^*Nsnd(M,N)→β∗​N。

同理，nnn 元组可编码为 (M1,…,Mn)≡λs.s M1⋯Mn(M_1,\ldots,M_n)\equiv\lambda s.s\,M_1\cdots M_n(M1​,…,Mn​)≡λs.sM1​⋯Mn​；第 iii 个投影把元组应用于选择器 λx1.⋯λxn.xi\lambda x_1.\cdots\lambda x_n.x_iλx1​.⋯λxn​.xi​。

例如，fst(A,B)→(λs.s A B) True→True A B→A\mathrm{fst}(A,B)\to (\lambda s.s\,A\,B)\,\mathrm{True}\to\mathrm{True}\,A\,B\to Afst(A,B)→(λs.sAB)True→TrueAB→A。三元组的第三项选择器是 λx.λy.λz.z\lambda x.\lambda y.\lambda z.zλx.λy.λz.z。

递归与不动点

若 F(g)=gF(g)=gF(g)=g，则 ggg 是 FFF 的不动点。递归定义可改写成寻找不动点：将递归调用暂时写成参数 ggg，构造函数生成器 FFF，再求满足 g=F(g)g=F(g)g=F(g) 的函数。

以阶乘为例（此处的条件、数字和乘法是便于阅读的记法）：

F≡λg.λn.  if n=0 then 1 else n×g(n−1).F\equiv\lambda g.\lambda n.\;\text{if }n=0\text{ then }1\text{ else }n\times g(n-1). F≡λg.λn.if n=0 then 1 else n×g(n−1).

阶乘函数满足 fact=F(fact)\mathrm{fact}=F(\mathrm{fact})fact=F(fact)；下一步需要构造一个能从 FFF 得到其不动点的纯 λ 项。

不动点组合子

定义 A≡λx.λf.f (x x f)A\equiv\lambda x.\lambda f.f\,(x\,x\,f)A≡λx.λf.f(xxf)，Θ≡A A\Theta\equiv A\,AΘ≡AA。按应用左结合，x x f=(x x) fx\,x\,f=(x\,x)\,fxxf=(xx)f。对任意项 FFF：

Θ F=(A A) F→β(λf.f (A A f)) F→βF ((A A) F)=F (Θ F).\Theta\,F=(A\,A)\,F\to_\beta(\lambda f.f\,(A\,A\,f))\,F\to_\beta F\,((A\,A)\,F)=F\,(\Theta\,F). ΘF=(AA)F→β​(λf.f(AAf))F→β​F((AA)F)=F(ΘF).

所以 Θ F\Theta\,FΘF 能不断展开为 F(Θ F)F(\Theta\,F)F(ΘF)，作为 FFF 的不动点来表达递归。这里的等号表示 β 等价意义上的不动点关系，不要求项在某种求值策略下都终止。讲义也给出 Church 的 Y≡λf.(λx.f (x x))(λx.f (x x))Y\equiv\lambda f.(\lambda x.f\,(x\,x))(\lambda x.f\,(x\,x))Y≡λf.(λx.f(xx))(λx.f(xx))。

例如令 G≡λg.λn.  if n=0 then 0 else n+g(n−1)G\equiv\lambda g.\lambda n.\;\text{if }n=0\text{ then }0\text{ else }n+g(n-1)G≡λg.λn.if n=0 then 0 else n+g(n−1)、S≡ΘGS\equiv\Theta GS≡ΘG。由 S→β∗G(S)S\to_\beta^*G(S)S→β∗​G(S)，再展开 GGG 可得 S(n)=if n=0 then 0 else n+S(n−1)S(n)=\text{if }n=0\text{ then }0\text{ else }n+S(n-1)S(n)=if n=0 then 0 else n+S(n−1)。

表达能力

纯 λ 演算仅含变量、抽象和应用，但可用函数编码布尔值、自然数、序对以及递归。λ 演算与图灵机在可计算函数的范围上等价；两者的语法和求值步骤不同。λ 演算的表达能力不意味着所有项都终止：Ω\OmegaΩ 是反例。–
