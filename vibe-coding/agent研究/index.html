OpenAI能力方式划分

OpenAI 现在明确把三种 surface 分工为：

Chat = conversation / reasoning；

Work = 长时间、多步骤、需要检索、文件、浏览器和最终 deliverable 的 Agent；

Codex = software development / repository work。

比较模型：能力 × 成本 × 延迟

现在 OpenAI 自己其实已经把模型做成了明显的分层：

模型 定位 建议任务
GPT-5.6 Luna 最快、最低成本 grep 后总结、改名字、小修改、格式化、提取信息
GPT-5.6 Terra 性能/速度/成本平衡 普通 coding、写测试、简单 bug、文档
GPT-5.6 Sol 强 reasoning 跨文件修改、复杂 bug、算法、论文分析
GPT-6 Astra 当前最强一档 困难研究问题、陌生大型 repo、复杂架构/bug、需要多步推理的问题

这不是单纯经验判断，OpenAI 官方现在也是这么定位的：Luna 用于 focused/repetitive task，Terra 用于 everyday work，Sol 用于复杂 coding/research/professional work，而 Astra 用于最困难的 coding、research、analysis 和 problem solving。

成本差距也很明显。例如 OpenAI 给出的 GPT-5.6 定位中，Luna 成本比 Sol 低约 80%，Terra 的目标则是以更低成本达到上一代强模型附近的能力。
