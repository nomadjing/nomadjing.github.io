为什么要搭建一个学习流

  • agent能及时提供反馈
  • 自行把控节奏
  • 学习流可以自定义和扩展

缺点

  • agent归纳课件(学习资源)–二手信息
  • 学习速度较慢

搭建属于自己的Agent学习流

无关工具,无关模型:选择任意一个agent: codex,claude code,pi,dsh

简单任务,快速尝试,:找出学习中一个比较固定的流程,尝试使用agent辅助,然后再考虑扩展
